# 屏幕环境感知功能 — 前后端对接接口文档

## 一、功能概述

| 项目 | 说明 |
|------|------|
| 功能名称 | 屏幕环境感知 |
| 功能描述 | 前端定时截取屏幕截图上传至后端，后端调用用户配置的视觉模型识别当前屏幕环境，将环境信息注入 AI 对话的系统提示词，使 AI 能感知用户处境并做出更贴心的回应 |
| 启用条件 | **仅当用户配置了视觉模型（modelType = multimodal）时自动启用**，未配置则接口返回失败，前端应停止定时截屏 |
| 上下文有效期 | 30 秒（Redis TTL），每次上传成功后刷新 |

---

## 二、API 接口

### 上传屏幕截图

| 项目 | 说明 |
|------|------|
| **URL** | `POST /api/screen-capture/upload` |
| **Content-Type** | `multipart/form-data` |
| **认证方式** | JWT Bearer Token（Header: `Authorization: Bearer <token>`） |

#### 请求参数

| 参数名 | 类型 | 必填 | 说明 |
|--------|------|------|------|
| `file` | File (MultipartFile) | 是 | 屏幕截图文件，支持 jpg/jpeg/png/gif/webp 格式 |

#### 请求示例

```http
POST /api/screen-capture/upload HTTP/1.1
Authorization: Bearer eyJhbGciOiJIUzI1NiJ9...
Content-Type: multipart/form-data; boundary=----WebKitFormBoundary

------WebKitFormBoundary
Content-Disposition: form-data; name="file"; filename="screenshot.jpg"
Content-Type: image/jpeg

<binary data>
------WebKitFormBoundary--
```

#### 响应格式

统一 `ResultVo` 结构：

```json
{
  "code": 200,
  "msg": "环境识别成功",
  "data": "用户正在浏览购物网站，页面上展示了几款耳机商品"
}
```

#### 响应码说明

| code | msg | data | 场景 |
|------|-----|------|------|
| 200 | 环境识别成功 | 环境描述文本 | 截图上传且视觉模型识别成功 |
| 401 | 未认证或token无效 | null | JWT Token 缺失或无效 |
| 500 | 未配置视觉模型，屏幕感知功能未启用 | null | 用户未配置 multimodal 类型模型 |
| 500 | 截图文件不能为空 | null | 上传的文件为空 |
| 500 | 环境识别失败 | null | 视觉模型调用异常或返回空结果 |
| 500 | 用户身份信息缺失 | null | JWT 解析后 openId 为空 |

## 三、功能启用判断

前端应在页面加载时判断是否需要启动定时截屏，推荐以下两种方案：

### 方案 A：调用上传接口试探

首次上传时，如果返回 `code: 500` 且 `msg` 包含 `"未配置视觉模型"`，则停止定时器，后续不再上传。

### 方案 B（推荐）：查询用户模型配置

复用现有的模型配置接口，检查用户当前偏好模型的 `modelType` 字段：

- 如果 `modelType === "multimodal"` → 启动定时截屏
- 如果 `modelType === "text"` 或无偏好 → 不启动

## 四、前端集成指南

### Web 端（html2canvas）

```javascript
import html2canvas from 'html2canvas';

class ScreenCaptureScheduler {
  constructor(apiBaseUrl, getToken) {
    this.apiBaseUrl = apiBaseUrl;
    this.getToken = getToken;
    this.timer = null;
    this.enabled = true;
  }

  start(intervalMs = 10000) {
    if (this.timer) return;
    this._captureAndSend();
    this.timer = setInterval(() => this._captureAndSend(), intervalMs);
  }

  stop() {
    if (this.timer) {
      clearInterval(this.timer);
      this.timer = null;
    }
  }

  async _captureAndSend() {
    if (!this.enabled) return;

    try {
      const canvas = await html2canvas(document.body, {
        scale: 0.5,
        useCORS: true,
        logging: false,
        imageTimeout: 5000,
      });

      const blob = await new Promise(resolve =>
        canvas.toBlob(resolve, 'image/jpeg', 0.6)
      );
      if (!blob) return;

      const formData = new FormData();
      formData.append('file', blob, 'screenshot.jpg');

      const response = await fetch(`${this.apiBaseUrl}/api/screen-capture/upload`, {
        method: 'POST',
        headers: {
          'Authorization': `Bearer ${this.getToken()}`,
        },
        body: formData,
      });

      const result = await response.json();

      if (result.code === 200) {
        console.log('[ScreenCapture] 环境已识别:', result.data);
      } else if (result.msg && result.msg.includes('未配置视觉模型')) {
        console.log('[ScreenCapture] 用户未配置视觉模型，停止截屏');
        this.enabled = false;
        this.stop();
      }
    } catch (error) {
      console.error('[ScreenCapture] 上传失败:', error);
    }
  }
}

// 使用
const scheduler = new ScreenCaptureScheduler(
  'https://your-api.com',
  () => localStorage.getItem('token')
);
scheduler.start(10000);

window.addEventListener('beforeunload', () => scheduler.stop());
```

### 微信小程序端

```javascript
Page({
  onShow() {
    this.startScreenCapture();
  },
  onHide() {
    this.stopScreenCapture();
  },
  onUnload() {
    this.stopScreenCapture();
  },

  startScreenCapture() {
    this.screenEnabled = true;
    this.screenTimer = setInterval(() => {
      if (!this.screenEnabled) return;
      this.captureAndSend();
    }, 10000);
  },

  stopScreenCapture() {
    if (this.screenTimer) {
      clearInterval(this.screenTimer);
      this.screenTimer = null;
    }
  },

  async captureAndSend() {
    try {
      const res = await new Promise((resolve, reject) => {
        wx.captureScreen({
          success: resolve,
          fail: reject,
        });
      });

      const uploadRes = await new Promise((resolve, reject) => {
        wx.uploadFile({
          url: `${this.data.apiBaseUrl}/api/screen-capture/upload`,
          filePath: res.tempFilePath,
          name: 'file',
          header: {
            'Authorization': `Bearer ${this.data.token}`,
          },
          success: (r) => resolve(JSON.parse(r.data)),
          fail: reject,
        });
      });

      if (uploadRes.code === 200) {
        console.log('[ScreenCapture] 环境已识别:', uploadRes.data);
      } else if (uploadRes.msg && uploadRes.msg.includes('未配置视觉模型')) {
        console.log('[ScreenCapture] 未配置视觉模型，停止截屏');
        this.screenEnabled = false;
        this.stopScreenCapture();
      }
    } catch (error) {
      console.error('[ScreenCapture] 截屏失败:', error);
    }
  },
});
```

## 六、注意事项

| 项目 | 说明 |
|------|------|
| **截图压缩** | 建议前端将截图缩放至 50% 并使用 JPEG 0.6 质量压缩，单张控制在 100-200KB，避免占用过多带宽 |
| **定时间隔** | 推荐 10 秒，后端 Redis TTL 为 30 秒，允许偶尔上传失败而不丢失上下文 |
| **功能降级** | 如果上传接口返回"未配置视觉模型"，前端应立即停止定时器，避免无效请求 |
| **隐私提示** | 建议在 UI 上告知用户屏幕感知功能已开启，并提供关闭开关 |
| **页面生命周期** | 页面隐藏/切换时停止截屏，页面恢复时重新启动 |
| **不存储截图** | 后端仅将截图作为临时文件处理，识别完成后立即删除，不会持久化到 OSS 或数据库 |
| **环境描述** | 视觉模型返回的环境描述限制在 50 字以内，仅保留关键信息，不会泄露详细内容 |
